## Architecture Decisions

### GitOps Model
- ArgoCD is the GitOps controller tracking this repo
- All platform services are declarative ArgoCD Applications
- Repo is source of truth; cluster state reconciles to git state
- Branch: `try-two` (tracked by all ArgoCD Applications)
- App of Apps: `platform/bootstrap/app-of-apps.yaml` watches `platform/apps/` — adding a file there auto-creates the app

### Installation Bootstrap Order
1. `helm install argocd` using `platform/bootstrap/argocd/values.yaml`
2. Bootstrap creates imperative secrets (linode-credentials, linode-token, grafana-admin-secret)
3. Bootstrap applies `platform/bootstrap/app-of-apps.yaml`
4. ArgoCD App of Apps discovers and manages all apps in `platform/apps/`

### Sync Waves (ArgoCD ordering)
```
Wave 1: cert-manager, crossplane          (infrastructure foundation)
Wave 2: traefik, crossplane-providers     (ingress + infra providers)
Wave 3: kro, o11y stack, external-dns, score  (platform services)
Wave 4: cert-manager-issuers             (depends on cert-manager + traefik)
```

### Multi-Source Pattern
All Helm-based ArgoCD Applications use the multi-source pattern:
```yaml
sources:
  - repoURL: <helm-chart-repo>
    chart: <chart>
    targetRevision: <version>
    helm:
      valueFiles: [$values/platform/helm/<service>/values.yaml]
  - repoURL: https://github.com/cmcgalliard/2026-oss-summit.git
    targetRevision: try-two
    ref: values
```

## Secrets Management
- `OSS_LINODE_API_TOKEN` env var → `linode-credentials` (crossplane-system, JSON format for Crossplane)
- `OSS_LINODE_API_TOKEN` env var → `linode-token` (external-dns, plain token for external-dns)
- Grafana admin → `grafana-admin-secret` (o11y, random password generated in bootstrap)
- ArgoCD admin → `argocd-initial-admin-secret` (argocd, auto-generated by ArgoCD chart)
- All secrets are created imperatively in bootstrap.sh (before ArgoCD sync)
